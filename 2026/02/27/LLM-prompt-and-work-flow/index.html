大语言模型提示词与工作流

绘图提示词

科研绘图提示词

gemini顶会绘图提示词

总体观感：画面留白充分、模块化分块清晰、阅读路径严格（左→右或上→下），用轻微投影/2.5D 等距视角表达层级关系；颜色采用低饱和、高明度的莫兰迪色做语义编码（同类模块同色），整体素净克制，但通过少量“柔和强调色”突出论文贡献点与关键对比结果。细节要求如下：
1) 核心视觉风格（Visual Style & Aesthetics） Flat 2.0（扁平 + 微立体） 主体扁平：无复杂高光、无渐变大面积铺陈、无强烈材质纹理。 层级表达：仅在需要区分前后关系时使用： 轻微投影（非常淡、短距离、软边缘） 或 2.5D / Isometric（用于张量、特征图、堆叠层） 强调点：论文贡献模块用“同一强调色 + 加粗描边/标题标签”突出，但不喧宾夺主。 线条与边框（Vector-first） 全部元素保持矢量锐利边缘（SVG/PDF 输出），避免截图拼贴。 连接线以直线/圆角折线为主，曲线仅用于表达“反馈/循环”且走线克制。 线宽分级明确：主流程 > 次流程 > 注释引线；箭头简洁统一。
2) 内容布局与逻辑（Layout & Logic） 视觉流（Flow） 强制遵循：Input 在最左/最上，Output 在最右/最下。 关键路径清晰可追踪：主干线更粗、颜色更“确定”；辅助分支更细或虚线。 模块化与秩序感（Modularity） 复杂系统拆成若干功能块（Encoder / Decoder / Retriever / Loss / Render / Post-process）。 对齐与间距高度一致：所有模块边缘对齐或中心对齐，Padding/Margin 统一，形成“工程图纸”式秩序。 信息层级：先看结构与趋势，再看细节（尺寸、公式、超参放在角落或二级标注）。
3) 三类顶会常用插图的“标准画面” A. 首页图（Teaser / Pull Figure） 目的：3 秒理解“解决什么 + 为什么好”。 画面结构： 左侧：传统方法问题/输入（如模糊、噪声、遮挡、低分辨率）。 中间：用极简示意（半透明流程或一个核心模块图标）表示“本文关键点”。 右侧：本文效果（对比强烈但公平），必要时加一列 Baseline 作为参照。 文字：短、粗、少（1–2 行），强调“更清晰/更稳定/更一致/更高保真”等结果词。 B. 方法架构图（Pipeline / Architecture） 核心语言：模块块图 + 张量体积 + 语义颜色 + 数学符号点到为止。 典型元素： 张量用长方体/薄片堆叠表示，尺寸变化直观体现（Pooling 变小、Upsample 变大）。 操作用矩形/梯形块表示（Conv、Attention、Fusion、Loss），在关键处嵌入 LaTeX 风格符号（⊕、⊗、concat 等）。 复杂模块（如 Transformer block）用引线 + 放大框放在空白区展开内部结构，避免主流程拥挤。 新贡献模块：使用固定强调色 + “Our”标签 + 更醒目的标题，但仍保持整体克制。 C. 数据图表（Charts & Plots） 风格接近精修后的 Matplotlib/ggplot：弱网格/无背景块，只保留必要轴线与刻度。 曲线/柱状图：线条略粗、标记清晰；图例尽量放在图内空白处不遮数据。 兼顾黑白打印：用线型（实/虚/点划）+ 形状辅助区分，而不是只靠颜色。
4) 莫兰迪配色方案（素净但不灰） 目标：低饱和 + 高明度 + 暖中性底色，整体干净，但绝不“死灰”。
推荐基础色（可直接用作调色板）
雾霾蓝 / Dusty Blue：#6F8FB6
鼠尾草绿 / Sage：#8FAE9A
薄荷青 / Muted Mint：#9FC2B4
柔珊瑚 / Muted Coral：#D08C7A
灰紫丁香 / Soft Lavender：#A8A0C8
奶油米 / Warm Sand（背景底）：#EFE7DB
深墨褐 / Warm Charcoal（正文文字）：#2F2B28
语义配色规则（保证“顶会一致性”）
同类模块同色：例如 Encoder 系统一律雾霾蓝，Decoder/Refine 系统一律鼠尾草绿。
Loss / Error / Gradient 用柔珊瑚（醒目但不刺眼）。
Attention / Mask / Weight map 用灰紫丁香或薄荷青（区分语义层）。
对比方法（Baselines）尽量用同色系的更浅版本 + 虚线（避免“颜色抢戏”）。
全图强调色不超过 1–2 个；总色相不超过 4–5 个。
5) 字体与标注规范（Typography）
英文与标签：Helvetica / Arial（现代、干净）。
数学符号：与论文 LaTeX 一致（Times 系衬线斜体风格即可）。
字号策略：在双栏缩放下仍可读；宁可减少文字也不把字缩小。
子图标记：(a)(b)(c) 固定位置与格式，保证全篇一致。
6) 一眼像顶会的“细节参数”
圆角：轻微统一（模块边角柔和但不“卡通”）。
投影：极淡、短距离、软边缘，只用于层级分离（不做浮夸卡片风）。
间距：统一栅格（例如 8pt/10px 逻辑间距），模块之间留白明确。
输出：优先 PDF/SVG，避免位图锯齿；若必须位图，分辨率足够且无 UI 边。
